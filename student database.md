

This project creates a simple College Database Management System using MySQL. It demonstrates database creation, tables, constraints, relationships, and sample data insertion.

Database

Database Name: college_demo

Tables
department – Stores department details.
student – Stores student information and their department.
course – Stores courses offered by departments.
enrollment – Records students enrolled in courses, along with semester and grade.
faculty – Stores faculty information and their department.
Key Features
Primary and foreign keys
UNIQUE and NOT NULL constraints
CHECK constraint for semester
Relationships between students, courses, departments, and faculty
Sample student, course, enrollment, and faculty records
How to Run
Open MySQL Workbench or any MySQL client.
Copy and execute the SQL script.
The college_demo database and all required tables will be created automatically.
